# Single-Bacterial Cell Insights into Mechanisms of Ceftriaxone Resistance in *Neisseria subflava*

This repository contains the R scripts for the single-bacterial RNA-seq analysis of *Neisseria subflava*. The study aims to uncover the mechanisms behind ceftriaxone resistance in this bacterial species.

## Manuscript Details

- **Title:** Single-Bacterial Cell Insights into Mechanisms of Ceftriaxone Resistance in *Neisseria subflava*  
- **DOI:** https://doi.org/10.1038/s41467-026-68621-y
- **Link:** https://www.nature.com/articles/s41467-026-68621-y 

## Contents of the Repository

- `seurat.R`: R script detailing the pipeline used for single-bacterial transcriptome analysis.
- `1.STARsolo`: count data matrices of the single bacterial RNAseq

## Overview

This project leverages single-bacterial RNA-seq to identify and analyze the transcriptomic signatures associated with ceftriaxone resistance in *Neisseria subflava*. The analysis pipeline is implemented using [Seurat](https://satijalab.org/seurat/) for single-cell data analysis.  

### Key Features

- Single-bacterial RNA-seq pipeline tailored for *Neisseria subflava*  
- Identification of genes and pathways contributing to ceftriaxone resistance  
- Comprehensive R script (`seurat.R`) to reproduce the analysis
